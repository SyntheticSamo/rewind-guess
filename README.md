# 倒带 REWIND · 听倒放猜歌

导入网易云公开歌单，随机抽歌，将实际音频的一段倒过来播放，适合朋友聚会时共用屏幕猜歌。

[在线试玩 · 倒带 REWIND](https://syntheticsamo.github.io/rewind-guess/)

## 开始使用

Windows 双击 `start.cmd`。工具会启动本地服务并打开浏览器。保持终端窗口开启，按 Ctrl+C 停止服务。

也可以安装 Node.js 22 或以上版本，在项目文件夹运行：

```powershell
node scripts/serve.mjs
```

在浏览器打开 http://127.0.0.1:4317 。不需要安装任何 npm 依赖。

1. 粘贴网易云歌单链接、歌单 ID 或分享文字，点击「读取歌单」。大歌单会按照歌曲 ID 分批补齐详情。
2. 选择每局回合数：3 / 5 / 10 / 15 / 20 / 30，或自定义 1–100 回合。开局后固定；新一局开始前可修改。如果歌单歌曲更少，回合数会相应缩减。
3. 选择 5 / 10 / 15 / 20 / 30 秒，以及随机片段、歌曲中段或开头。
4. 点击「随机抽一首」，开始倒放。抽歌时检查音源，跳过当前没有提供音频的歌曲。同一局不会重复抽取，音源加载失败不占回合。
5. 可以暂停、继续、重播。点击「揭晓答案」查看歌名与歌手，「听原片段」正放同一段音频。
6. 标记猜对得 1 分、没猜中得 0 分，跳过未标记的题也得 0 分。最后一题标记后自动显示总分、正确率与逐题结果；也可以点击「完成本局」按当前计分结算。
7. 可以再次「查看总分」，或点击「开始新一局」清零战绩并重新洗牌。可用歌曲提前用完时，会按实际出题数结算并说明原因。

快捷键：Space 播放 / 暂停，R 揭晓，N 下一首。输入框或对话框获得焦点时不会抢占键盘操作；按钮和链接保留原本的空格键操作。全屏可隐藏主持人的设置区域。

## 网易云歌单和音源

网页版可通过 GitHub Pages 托管。运行 `node scripts/build-pages.mjs` 生成 `docs/`，将 GitHub Pages 发布来源设置为 main 分支的 `/docs`。页面资源使用相对路径，支持项目网址的子目录。网易云接口由公开后端处理，后端的 `PAGES_ORIGIN` 环境变量仅允许所用 GitHub Pages 源站（例如 `https://username.github.io`）发起跨域浏览器请求。前端配置文件只包含公开后端网址，不包含令牌、Cookie 或私有凭证。

- 支持桌面和移动版完整歌单链接、带 `#/playlist` 的链接、歌单 ID，以及通过标准 HTTP 跳转分享的 `163cn.tv` / `163cn.link` 短链接。短链接解析失败时，请改用网页版完整链接。
- 最多导入 5000 首。导入完成会显示读取数量；如果网易云少返回了歌曲详情，明确提示缺失数量。
- 不需要网易云账号，仅请求网易云当前返回的公开音源。会员、下架、登录或地区限制等情况可能没有音频。能读取歌单并不代表所有歌曲都能播放。
- 如果网易云只返回试听音频，游戏会标明「试听」；截取位置是试听音频内部的位置。
- 不会索要密码、会员 Cookie，也没有会员或地区限制解锁功能。接口是网易云当前 Web 接口，未来变化时需要维护。
- 音源地址在服务端校验，只允许网易云音频 CDN；不依赖第三方歌单解析或公共代理服务。线上音频以流的形式转发，浏览器解码后仅保留当前题目的片段。
- 在线服务使用 Cloudflare Workers 支持的手动重定向模式，避免 Node 本地运行正常而线上请求尚未发出便报错的兼容问题；上游连接错误不会被当作歌曲无音源而消耗题目。

## 本地音频

「本地音频」按钮会建立独立本地歌单。歌曲答案默认从文件名推断：`歌手 - 歌名.mp3`，没有分隔符时使用文件名。主持人歌单里可以编辑答案。

网易云歌单的「主持人歌单 → 绑定本地音频」可以为现有歌曲补充音频：

- 批量匹配按歌曲 ID、完整歌名或「歌手 - 歌名」进行；有多个候选时不自动猜测。
- 也可以搜索歌曲，在该歌曲右侧点击「绑定」，手动选择音频。
- 绑定后，此前因音源不可用而跳过、尚未出题的歌曲会重新加入待抽取队列。

文件在浏览器本地处理，不上传。刷新或关闭后需重新选择。支持情况由浏览器解码能力决定，推荐 MP3 / WAV；不支持 NCM 加密文件。单个本地文件上限 100 MB，在线音频上限 40 MB，过大的解码音频也会拒绝载入。

「试试演示」提供小星星、欢乐颂、两只老虎的浏览器合成旋律，可在没有网络或音频文件时体验玩法。这些是合成示范，并非网易云录音。

## 开发和验证

```powershell
node --test tests/*.test.mjs
node scripts/build.mjs
node scripts/validate-artifact.mjs
```

- `web/`：中文界面、播放状态、逐声道采样倒序、截取与随机牌堆。
- `worker/index.js`：网易云歌单补全、音源检查与受限音频转发。
- `scripts/serve.mjs`：本地 Node 适配器，默认仅监听 127.0.0.1。
- `scripts/build.mjs`：将浏览器资源嵌入单个 Worker，输出 `dist/server/index.js`。
- `.openai/hosting.json`：可选的 Sites 部署标识，本地运行不需要；公共 GitHub 源码不包含此文件。

页面默认只记住上次填写的歌单链接，不自动访问。歌单、战绩和本地文件仅保留在本次页面会话。不会在源代码中保存导入的歌单内容或音频。
