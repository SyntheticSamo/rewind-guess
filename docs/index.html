倒过来，听听看。

  1. 准备歌单

    粘贴网易云公开歌单链接或分享文字，点击「读取歌单」。也可以选择本地音频，或试试三首合成演示旋律。

  2. 随机抽歌

    选择片段长度和截取位置，点击「随机抽一首」。本轮不会抽到同一首歌；取不到音频的歌曲会跳过。

  3. 听倒放，猜歌名

    倒放播放的是实际音频片段。重播始终播放本题的同一个片段，可以暂停继续。

  4. 揭晓答案

    查看歌名和歌手，还可以正放同一片段作对照。自行记录是否猜对，再进入下一首。

仅尝试网易云当前提供的公开音源，无需账号。部分会员、下架或受地区限制的歌曲无法取得音频；支持按歌名、歌手或歌曲 ID 匹配本地音频。MP3、WAV 等格式取决于浏览器支持，NCM 加密文件不支持。关闭或刷新后需重新选择本地文件。
